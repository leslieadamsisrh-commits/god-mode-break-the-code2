# GOD MODE Animation Library — v4.0

Canonical animation workflow for the Combat Lab.

## Status pipeline
REFERENCE → SKELETON VALIDATED → FINAL ART READY

## Production rule
Do not add final manga frames until the skeleton family is validated in gameplay.

## Priority families
1. Cover — Slide to Cover
2. Cover — Attached / Corner Peek / Pop-fire
3. Locomotion — Roadie-style run, starts, stops, turns
4. Traversal — Cover slip, transfer, mantle/vault, exits
5. Combat — firearm handling and Power Glove melee
6. Psychic — Grip, Shield/Parry, Pinball, Slow Time, Create Cover
7. Reactions / finishers

## Slide-to-cover canonical pose chain
RUN → ANTICIPATION → BODY DROP → SLIDE ENTRY → FULL EXTENSION → COVER ANTICIPATION → IMPACT → MAX COMPRESSION → SETTLE → ATTACHED READY

Each pose must preserve center-of-mass logic, planted/supporting limb intent, segmented spine behavior, independent head aim, shoulder/elbow/wrist weapon chain, and cover contact.

## Cover peek canonical pose chain
ATTACHED → HEAD PEEK → SPINE TWIST → SHOULDER CLEAR → HANDS CLEAR → MUZZLE CLEAR → POP-FIRE

Pelvis remains committed to cover until an explicit exit action.
