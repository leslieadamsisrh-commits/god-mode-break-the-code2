## Director lock

GOD MODE is now a 3D-first production.

Runtime characters, movement, collision, cover, weapons, physics, destruction, verticality, and multiplayer state must be real 3D systems.

The visual target remains the approved 2.5D / elevated three-quarter living-comic presentation through cel shading, ink outlines, manga overlays, emissive accents, UI, impact frames, and selective 2D FX.

Do not return to mass-producing directional sprite libraries as the primary movement solution.

## Blender decision

Blender is the canonical 3D content creation tool for:
- modeling
- rigging
- skinning
- animation
- weapons
- props
- environment source assets
- source materials
- look development
- export preparation

Blender is not the multiplayer runtime engine.

The first lookdev target is a limited `GM_JADE_LOOKDEV_PROXY`, not the final shipping model.

Use an EEVEE cel lookdev workflow with stepped light/shadow bands and camera-aware line testing. Recreate the approved look in the final runtime engine rather than depending on Blender-only shader nodes.
