These 18 transparent sprites are drawing candidates for front-right, left and back-left. Each direction has a catch, hold, two shuffle steps, low pop and tall aim. Registration records the source crop and provisional pelvis, support-foot, scale and muzzle landmarks. The active manifest and stationary-wrap install script exclude these files.

Review the foot plant and shotgun grip across each adjacent pair at the game camera. Calibrate scale against the standing sprite, measure barrel clearance on the projected wall, and finish both tall-edge tuck and pivot paths before activating a family.
