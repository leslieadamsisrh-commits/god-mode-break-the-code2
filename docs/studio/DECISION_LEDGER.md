# DECISION LEDGER

Use this ledger for decisions that must survive chat boundaries.

Status values:
- LOCKED — current authority.
- TESTING — active candidate, not yet authority.
- PARKED — valid idea, not scheduled.
- SUPERSEDED — historical; replaced by a newer decision.

## LOCKED

### Project identity
- Title: GOD MODE: BREAK THE CODE
- The current repository/app is the product being evolved. Do not start a competing replacement codebase merely to reorganize production.

### Production system
- The playable app/code outranks documentation.
- New ideas do not automatically enter production.
- Stable/approved systems are protected by regression gates.
- Work proceeds through isolated, reversible passes.

### Current combat gate
- Shotgun projectiles must originate from the actual barrel/muzzle transform.
- Visual pose, aim direction, projectile trajectory, and recoil origin must agree.
- Preserve the approved slide feel/effects while this gate is being solved.
