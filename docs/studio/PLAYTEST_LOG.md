### APPROVED / LOCK

### BUGS
- Severity:
- Reproduction:
- Expected:
- Actual:

### TUNING
- Feel/readability/pacing changes that are not hard failures.

### REGRESSIONS
- Anything that worked before and no longer works.

### IDEAS
- Capture only. Move to Idea Vault unless they directly solve the current gate.

### NEXT ACTION
One concrete highest-leverage task.

### PROTECTED SYSTEMS
List what the next implementation must not alter.
