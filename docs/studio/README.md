# GOD MODE: BREAK THE CODE — STUDIO

This folder is the durable production brain for GOD MODE.

## Authority order

1. Verified playable game build / current code.
2. Command Center current-state record.
3. Decision Ledger entries marked LOCKED.
4. Department specifications.
5. Historical chats, prompts, experiments, and superseded branches.

Historical material may inform work, but it may never silently override a newer locked decision.

## Non-regression rule

Studio documentation must never modify gameplay behavior, deployment settings, art runtime, networking, controls, or production assets by itself. Production changes happen only through an explicit implementation task, isolated branch, test pass, and approval gate.

## Operating loop

PLAY → CAPTURE → TRIAGE → IMPLEMENT → VERIFY → LOCK → PLAY
